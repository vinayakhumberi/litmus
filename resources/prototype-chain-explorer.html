3. class vs Object.create — Prove They're the Same Chain

Two completely different-looking ways to build the same relationship. Run both and compare what actually comes back.

Using class

class Animal {
  constructor(name) { this.name = name; }
  speak() { return `${this.name} makes a sound`; }
}
class Dog extends Animal {}
const rex = new Dog('Rex');

Using Object.create

const AnimalProto = {
  speak() { return `${this.name} makes a sound`; }
};
const DogProto = Object.create(AnimalProto);
const fido = Object.create(DogProto);
fido.name = 'Fido';

4. Object Shape: Monomorphic vs. Megamorphic, For Real

A page's JavaScript can't ask V8 directly "was that lookup monomorphic or megamorphic?" — but it can measure the real-world consequence. Below, the same property reads run millions of times against two object sets: one where every object shares an identical shape, one where the shape changes constantly. Same access pattern, same CPU, same amount of work — only shape consistency differs.

Run it a few times honestly expecting a small or near-zero gap on a modern machine, not a dramatic one — and that result is itself worth understanding, not a broken demo. Modern V8's megamorphic stub cache has gotten genuinely fast at exactly this kind of simple case; the classic "megamorphic is dramatically slower" mental model was truer of engines from several years ago than it typically is today. The mechanism described in the topic doc is completely real — shapes, inline caches, and the monomorphic/polymorphic/megamorphic ladder all genuinely exist and genuinely drive engine behavior — it's specifically the size of the everyday penalty that's shrunk as engines improved, which is a more accurate, more useful thing to walk away knowing than a memorized "always X times slower."

Honest caveat: across repeated runs while building this demo, the megamorphic pass was often no slower than the monomorphic one on modern desktop Chrome — not a fluke, a genuine sign of how good V8's megamorphic stub cache has gotten for simple property reads. Don't take a ~1.0× result here as "the concept is wrong" — take it as real evidence that the everyday penalty is smaller than the folklore suggests, which is exactly the nuance worth carrying into an interview over a memorized "megamorphic is always slow."
