1. The bug this page reproduces

40 ProductRow components, each wrapped in React.memo. A "tick" button simulates something unrelated re-rendering the shared parent — think of it as a clock in the header, or any sibling state change that has nothing to do with the product list.

With the bug present, the parent defines onSelect as a fresh arrow function on every render, including the unrelated tick updates — a new reference every time, which defeats every row's React.memo check even though no product data changed.

// BUG: new function reference every render, even for unrelated ticks
const onSelect = (id) => selectProduct(id);

// FIX: stable reference across renders
const onSelect = useCallback((id) => selectProduct(id), []);
